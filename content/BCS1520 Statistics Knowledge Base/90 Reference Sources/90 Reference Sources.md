# 90 Reference Sources — BCS1520

Index of all source materials in `Materials/`. The folder is organised study-first:

```
Materials/
├── 00 Exam Critical/        Grab these first
├── 01 Lectures/             L1–L8 in chronological order
├── 02 Exercises by Topic/   Exercises + solutions, grouped by KB topic number
├── 03 Python Tutorials/     Jupyter notebooks (not exam-tested)
└── 99 Reference/            Supporting materials
```
