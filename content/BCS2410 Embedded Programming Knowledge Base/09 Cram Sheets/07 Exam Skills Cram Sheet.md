# 07 Exam Skills Cram Sheet

High-yield solution workflows, recall tables, and traps that show up in quizzes and likely exam questions.

## Core Distinctions

| Workflow | Fast rule |
| --- | --- |
| Conversion problems | Move between binary, decimal, and hex systematically; do not guess. |
| Pointer problems | Separate address, pointed-to value, and pointer arithmetic step size. |
| Assembly branch problems | Decide signed or unsigned first, then choose the correct condition code. |
| Stack/procedure problems | Track LR, SP, argument registers, and who is responsible for preserving what. |

## Fast Recall

- Use a repeatable method for number conversion problems.
- Use a repeatable method for pointer and memory-layout questions.
- A typical `int` on the course's 32-bit platform is 4 bytes.
- Decimal 25 is binary `11001`.
